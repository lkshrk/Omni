# MCP Server Management Implementation Plan (Agents Phase 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement declarative MCP server management in omni — declare servers in `settings.json`, restore them into Claude Code and Codex via their CLIs, detect unmanaged servers, and surface everything in the TUI's existing `mcp` filter chip (currently a "No MCP servers tracked yet." stub at `skillTypeIdx == 1`).

**Architecture:** A `McpAdapter` interface (one file per agent) delegates all writes to the agent's own CLI — never direct config-file edits. App-layer operations (add/remove/restore/import/status) compose over adapters and mirror the skills-operation pattern (`withConfig` + `fallbackExecutor().Run`). The TUI replaces the stub with real rows, reusing the spinner, agents-picker, and `renderSectionedTab` machinery already in place.

**Tech Stack:** Go, `github.com/spf13/cobra`, Bubbletea TUI (`charm.land/bubbletea/v2`), `claude` and `codex` binaries exec'd via `a.fallbackExecutor().Run`, `txtar` integration tests.

## Global Constraints

- **Write mechanism — CLI delegation only. Never write agent config files directly.**
  - Claude Code: `claude mcp add -s user <name> [-e KEY=VALUE...] -- <cmd> [args...]` (stdio); `claude mcp add -s user <name> --transport http|sse <url>` (http/sse); `claude mcp list`; `claude mcp remove -s user <name>`
  - Codex: `codex mcp add [--env KEY=VALUE...] <name> -- <cmd> [args...]` (stdio); `codex mcp add <name> --url <url>` (http); `codex mcp list`; `codex mcp remove <name>`
- **Secrets:** `McpServer.Env` stores env var names only. Values resolved from omni's environment via `os.LookupEnv` at add/restore time. A missing var is a per-server non-fatal error; empty values are never written.
- **Unmanaged servers:** `List()` + import only. omni never edits or removes a server it did not add.
- No `_ =` error discards anywhere.
- Comments: near-zero; one-line WHY only.
- Conventional Commits per logical unit; commit after each task before starting the next.
- Config schema changes are additive. Bump `CurrentVersion` from `9` to `10` and run `make gen-schema` after config changes.
- **TUI tests:** ALL TUI test code is written by the **tui-tester** agent. Never inline TUI test code.
- **txtar fixtures:** ALL `.txtar` integration test files are written by the **txtar-writer** agent. Never inline `.txtar` content.

```go
func validateMcpServers(servers []McpServer, path string) []ValidationError {
    var errs []ValidationError
    seen := make(map[string]struct{}, len(servers))
    for i, s := range servers {
        p := fmt.Sprintf("%s[%d]", path, i)
        if strings.TrimSpace(s.Name) == "" {
            errs = append(errs, ValidationError{Path: p + ".name", Message: "mcp_server name must not be empty"})
        } else if _, dup := seen[s.Name]; dup {
            errs = append(errs, ValidationError{Path: p + ".name", Message: fmt.Sprintf("duplicate mcp_server name %q", s.Name)})
        }
        seen[s.Name] = struct{}{}
        switch s.Transport {
        case "stdio":
            if strings.TrimSpace(s.Command) == "" {
                errs = append(errs, ValidationError{Path: p + ".command", Message: "stdio transport requires command"})
            }
            if s.URL != "" {
                errs = append(errs, ValidationError{Path: p + ".url", Message: "stdio transport must not set url"})
            }
        case "http", "sse":
            if strings.TrimSpace(s.URL) == "" {
                errs = append(errs, ValidationError{Path: p + ".url", Message: fmt.Sprintf("%s transport requires url", s.Transport)})
            }
            if s.Command != "" {
                errs = append(errs, ValidationError{Path: p + ".command", Message: fmt.Sprintf("%s transport must not set command", s.Transport)})
            }
        default:
            errs = append(errs, ValidationError{Path: p + ".transport", Message: fmt.Sprintf("unknown transport %q; must be stdio, http, or sse", s.Transport)})
        }
    }
    return errs
}
```

```go
package app

import (
    "context"

    "github.com/lkshrk/omni/internal/config"
)

// McpAdapter manages MCP servers in one target agent by delegating to that
// agent's own CLI. omni never edits agent config files directly.
type McpAdapter interface {
    ID() string
    Available() bool
    List(ctx context.Context) ([]InstalledMcpServer, error)
    Add(ctx context.Context, s config.McpServer) error
    Remove(ctx context.Context, name string) error
}

// InstalledMcpServer is one MCP server as reported by an agent's list output.
type InstalledMcpServer struct {
    Name      string
    Transport string
    Command   string
    URL       string
}

type execFn      func(context.Context, string, ...string) (string, string, error)
type lookupEnvFn func(string) (string, bool)
```

- [ ] **Step 4: Create mcp_claude_adapter.go**

Key responsibilities:
1. `Available()`: attempt `exec.LookupPath("claude")` or probe by running `claude --version`; return false without error if binary absent.
2. `Add()` for stdio:
   - For each name in `s.Env`, call `lookupEnv(name)`. If not found, return `fmt.Errorf("env var %q not set for server %q", name, s.Name)` before exec.
   - Build args: `["mcp", "add", "-s", "user", s.Name]` + `-e KEY=value` for each resolved env + each `s.EnvLiteral` entry + `["--"]` + `strings.Fields(s.Command)`.
3. `Add()` for http/sse:
   - Build args: `["mcp", "add", "-s", "user", s.Name, "--transport", s.Transport, s.URL]` + `-e` flags.
4. `Remove()`: `["mcp", "remove", "-s", "user", name]`.
5. `List()`: run `["mcp", "list"]`, parse text output line by line. Each line format (observed): `<name> (<transport>[, scope]): <command-or-url>`. Lines that don't match the pattern are silently skipped (best-effort import).

```go
package app

import (
    "context"
    "fmt"
    "os/exec"
    "strings"

    "github.com/lkshrk/omni/internal/config"
)

type claudeCodeMcpAdapter struct {
    exec      execFn
    lookupEnv lookupEnvFn
}

// NewClaudeCodeMcpAdapter returns a McpAdapter that delegates to the claude CLI.
func NewClaudeCodeMcpAdapter(exec execFn, lookupEnv lookupEnvFn) McpAdapter {
    return &claudeCodeMcpAdapter{exec: exec, lookupEnv: lookupEnv}
}

func (a *claudeCodeMcpAdapter) ID() string { return "claude-code" }

func (a *claudeCodeMcpAdapter) Available() bool {
    _, err := exec.LookupPath("claude")
    return err == nil
}

func (a *claudeCodeMcpAdapter) Add(ctx context.Context, s config.McpServer) error {
    envArgs, err := resolveEnvArgs(s, a.lookupEnv)
    if err != nil {
        return err
    }
    var args []string
    switch s.Transport {
    case "stdio":
        args = append([]string{"mcp", "add", "-s", "user", s.Name}, envArgs...)
        args = append(args, "--")
        args = append(args, strings.Fields(s.Command)...)
    case "http", "sse":
        args = []string{"mcp", "add", "-s", "user", s.Name, "--transport", s.Transport, s.URL}
        args = append(args, envArgs...)
    default:
        return fmt.Errorf("unsupported transport %q for server %q", s.Transport, s.Name)
    }
    if _, stderr, err := a.exec(ctx, "claude", args...); err != nil {
        return fmt.Errorf("claude mcp add %s: %w: %s", s.Name, err, stderr)
    }
    return nil
}

func (a *claudeCodeMcpAdapter) Remove(ctx context.Context, name string) error {
    if _, stderr, err := a.exec(ctx, "claude", "mcp", "remove", "-s", "user", name); err != nil {
        return fmt.Errorf("claude mcp remove %s: %w: %s", name, err, stderr)
    }
    return nil
}

func (a *claudeCodeMcpAdapter) List(ctx context.Context) ([]InstalledMcpServer, error) {
    stdout, _, err := a.exec(ctx, "claude", "mcp", "list")
    if err != nil {
        return nil, fmt.Errorf("claude mcp list: %w", err)
    }
    return parseClaudeMcpList(stdout), nil
}

// resolveEnvArgs builds -e KEY=value args for s.Env (resolved from environment)
// and s.EnvLiteral (inline). Returns error if any Env name is unset.
func resolveEnvArgs(s config.McpServer, lookupEnv lookupEnvFn) ([]string, error) {
    var args []string
    for _, name := range s.Env {
        val, ok := lookupEnv(name)
        if !ok {
            return nil, fmt.Errorf("env var %q not set for mcp server %q", name, s.Name)
        }
        args = append(args, "-e", name+"="+val)
    }
    for k, v := range s.EnvLiteral {
        args = append(args, "-e", k+"="+v)
    }
    return args, nil
}

// parseClaudeMcpList parses `claude mcp list` text output.
// Lines not matching the expected pattern are silently skipped.
func parseClaudeMcpList(out string) []InstalledMcpServer {
    // ... line-by-line best-effort parse ...
    // Line format varies by claude version; best effort.
    var result []InstalledMcpServer
    for _, line := range strings.Split(out, "\n") {
        line = strings.TrimSpace(line)
        if line == "" || strings.HasPrefix(line, "#") {
            continue
        }
        // Try to extract name from "name (transport...): ..." pattern
        paren := strings.Index(line, "(")
        if paren < 0 {
            continue
        }
        name := strings.TrimSpace(line[:paren])
        rest := line[paren+1:]
        close := strings.Index(rest, ")")
        if close < 0 {
            continue
        }
        meta := strings.ToLower(rest[:close])
        var transport string
        switch {
        case strings.Contains(meta, "http"):
            transport = "http"
        case strings.Contains(meta, "sse"):
            transport = "sse"
        default:
            transport = "stdio"
        }
        after := strings.TrimSpace(rest[close+1:])
        after = strings.TrimPrefix(after, ":")
        after = strings.TrimSpace(after)
        srv := InstalledMcpServer{Name: name, Transport: transport}
        if transport == "stdio" {
            srv.Command = after
        } else {
            srv.URL = after
        }
        result = append(result, srv)
    }
    return result
}
```

```go
package app

import (
    "context"
    "fmt"
)

// RestoreMcpOptions controls a restore run.
type RestoreMcpOptions struct {
    DryRun bool
}

// RestoreMcpResult summarizes a restore run.
type RestoreMcpResult struct {
    Installed []string       // "agentID/serverName" entries added
    Skipped   []string       // servers not targeting this agent, or dry-run
    Warnings  []string       // agent-unavailable notices
    Errors    []McpServerError // per-server add failures (non-fatal)
}

// McpServerError is a non-fatal per-server failure during restore.
type McpServerError struct {
    AgentID    string
    ServerName string
    Err        error
}

func (e McpServerError) Error() string {
    return fmt.Sprintf("agent %s / server %s: %v", e.AgentID, e.ServerName, e.Err)
}

// McpImportDiff lists servers detected by agent CLIs that are not in the manifest.
type McpImportDiff struct {
    Unmanaged map[string][]InstalledMcpServer // keyed by agent ID
}

// resolveMcpServers returns the servers active for groupName: ungrouped servers
// always appear; grouped servers appear only when their group matches.
func resolveMcpServers(cfg *config.RootConfig, groupName string) []config.McpServer {
    // Build a set of server names that appear in any GroupConfig.McpServers whose
    // group matches groupName. Servers with no group membership restore everywhere.
    // Mirror the logic of resolveSkillPackages in agents_skills.go.
    // ...
}

// serverTargetsAdapter reports whether server s should be applied to the given adapter.
// An empty Agents list means all adapters.
func serverTargetsAdapter(s config.McpServer, adapterID string) bool {
    if len(s.Agents) == 0 {
        return true
    }
    for _, id := range s.Agents {
        if id == adapterID {
            return true
        }
    }
    return false
}

func (a *App) RestoreMcpServers(ctx context.Context, opts RestoreMcpOptions) (RestoreMcpResult, error) {
    cfg, err := a.loadConfig()
    if err != nil {
        return RestoreMcpResult{}, err
    }
    if err := a.requireAgentsEnabled(cfg); err != nil {
        return RestoreMcpResult{}, err
    }
    servers := resolveMcpServers(cfg, currentMachineGroupName())
    var res RestoreMcpResult
    for _, adapter := range a.mcpAdapters() {
        if !adapter.Available() {
            res.Warnings = append(res.Warnings, fmt.Sprintf("agent %s not available, skipping", adapter.ID()))
            continue
        }
        for _, s := range servers {
            if !serverTargetsAdapter(s, adapter.ID()) {
                res.Skipped = append(res.Skipped, adapter.ID()+"/"+s.Name)
                continue
            }
            if opts.DryRun {
                res.Skipped = append(res.Skipped, adapter.ID()+"/"+s.Name)
                continue
            }
            if err := adapter.Add(ctx, s); err != nil {
                res.Errors = append(res.Errors, McpServerError{AgentID: adapter.ID(), ServerName: s.Name, Err: err})
                continue
            }
            res.Installed = append(res.Installed, adapter.ID()+"/"+s.Name)
        }
    }
    return res, nil
}

func (a *App) AddMcpServer(ctx context.Context, s config.McpServer) error {
    cfg, err := a.loadConfig()
    if err != nil {
        return err
    }
    if err := a.requireAgentsEnabled(cfg); err != nil {
        return err
    }
    for _, adapter := range a.mcpAdapters() {
        if !serverTargetsAdapter(s, adapter.ID()) {
            continue
        }
        if !adapter.Available() {
            continue
        }
        if err := adapter.Add(ctx, s); err != nil {
            return fmt.Errorf("add to %s: %w", adapter.ID(), err)
        }
    }
    return a.withConfig(func(c *config.RootConfig) error {
        c.Agents.McpServers = upsertMcpServer(c.Agents.McpServers, s)
        return nil
    })
}

func (a *App) RemoveMcpServer(ctx context.Context, name string) error {
    cfg, err := a.loadConfig()
    if err != nil {
        return err
    }
    if err := a.requireAgentsEnabled(cfg); err != nil {
        return err
    }
    var target *config.McpServer
    for i := range cfg.Agents.McpServers {
        if cfg.Agents.McpServers[i].Name == name {
            target = &cfg.Agents.McpServers[i]
            break
        }
    }
    if target == nil {
        return fmt.Errorf("mcp server %q not found in manifest; omni only removes servers it added", name)
    }
    for _, adapter := range a.mcpAdapters() {
        if !serverTargetsAdapter(*target, adapter.ID()) {
            continue
        }
        if !adapter.Available() {
            continue
        }
        if err := adapter.Remove(ctx, name); err != nil {
            return fmt.Errorf("remove from %s: %w", adapter.ID(), err)
        }
    }
    return a.withConfig(func(c *config.RootConfig) error {
        c.Agents.McpServers = deleteMcpServer(c.Agents.McpServers, name)
        return nil
    })
}

func (a *App) ImportMcpServers(ctx context.Context) (McpImportDiff, error) {
    cfg, err := a.loadConfig()
    if err != nil {
        return McpImportDiff{}, err
    }
    if err := a.requireAgentsEnabled(cfg); err != nil {
        return McpImportDiff{}, err
    }
    managed := make(map[string]struct{}, len(cfg.Agents.McpServers))
    for _, s := range cfg.Agents.McpServers {
        managed[s.Name] = struct{}{}
    }
    diff := McpImportDiff{Unmanaged: make(map[string][]InstalledMcpServer)}
    for _, adapter := range a.mcpAdapters() {
        if !adapter.Available() {
            continue
        }
        listed, err := adapter.List(ctx)
        if err != nil {
            continue // best-effort; non-fatal
        }
        for _, srv := range listed {
            if _, ok := managed[srv.Name]; !ok {
                diff.Unmanaged[adapter.ID()] = append(diff.Unmanaged[adapter.ID()], srv)
            }
        }
    }
    return diff, nil
}

// upsertMcpServer adds s or replaces the existing entry with the same name.
func upsertMcpServer(servers []config.McpServer, s config.McpServer) []config.McpServer {
    for i := range servers {
        if servers[i].Name == s.Name {
            servers[i] = s
            return servers
        }
    }
    return append(servers, s)
}

// deleteMcpServer removes the entry named name from servers.
func deleteMcpServer(servers []config.McpServer, name string) []config.McpServer {
    out := servers[:0]
    for _, s := range servers {
        if s.Name != name {
            out = append(out, s)
        }
    }
    return out
}
```

```go
package app

import "context"

// McpStatus is the per-adapter install state of a manifest server.
type McpStatus string

const (
    McpStatusInstalled        McpStatus = "installed"
    McpStatusMissing          McpStatus = "missing"
    McpStatusAgentUnavailable McpStatus = "agent-unavailable"
)

// McpServerRow is a display row for the TUI mcp tab and CLI list.
type McpServerRow struct {
    Name           string
    Transport      string
    Command        string
    URL            string
    Groups         []string
    Agents         []string            // configured targets
    PerAgentStatus map[string]McpStatus // keyed by adapter ID
}

// McpServerRows returns managed rows (from manifest) with per-adapter status,
// and unmanaged entries (detected by List() but not in the manifest), keyed by agent ID.
func (a *App) McpServerRows(ctx context.Context) (managed []McpServerRow, unmanaged map[string][]InstalledMcpServer, err error) {
    cfg, loadErr := a.loadConfig()
    if loadErr != nil {
        return nil, nil, loadErr
    }
    // Build the installed-name set per adapter.
    installedByAgent := make(map[string]map[string]InstalledMcpServer)
    unmanaged = make(map[string][]InstalledMcpServer)
    for _, adapter := range a.mcpAdapters() {
        if !adapter.Available() {
            installedByAgent[adapter.ID()] = nil
            continue
        }
        listed, listErr := adapter.List(ctx)
        if listErr != nil {
            // best-effort; show unknown status rather than aborting
            continue
        }
        byName := make(map[string]InstalledMcpServer, len(listed))
        for _, s := range listed {
            byName[s.Name] = s
        }
        installedByAgent[adapter.ID()] = byName
    }
    // Build managed rows.
    manifestNames := make(map[string]struct{}, len(cfg.Agents.McpServers))
    for _, s := range cfg.Agents.McpServers {
        manifestNames[s.Name] = struct{}{}
        row := McpServerRow{
            Name:           s.Name,
            Transport:      s.Transport,
            Command:        s.Command,
            URL:            s.URL,
            Agents:         append([]string(nil), s.Agents...),
            PerAgentStatus: make(map[string]McpStatus),
        }
        for _, adapter := range a.mcpAdapters() {
            byName, ok := installedByAgent[adapter.ID()]
            if !adapter.Available() {
                row.PerAgentStatus[adapter.ID()] = McpStatusAgentUnavailable
                continue
            }
            if !ok {
                continue
            }
            if _, found := byName[s.Name]; found {
                row.PerAgentStatus[adapter.ID()] = McpStatusInstalled
            } else {
                row.PerAgentStatus[adapter.ID()] = McpStatusMissing
            }
        }
        managed = append(managed, row)
    }
    // Build unmanaged entries.
    for _, adapter := range a.mcpAdapters() {

                unmanaged[adapter.ID()] = append(unmanaged[adapter.ID()], srv)
            }
        }
    }
    return managed, unmanaged, nil
```

```go
    var cmds []tea.Cmd
    switch {
    case key.Matches(msg, m.keys.Back): // esc
        m.mcpFormOpen = false
        m.mcpFormErr = nil
        m.resetMcpForm()
    case key.Matches(msg, m.keys.Tab):
        m.mcpFormField = (m.mcpFormField + 1) % 5
        m.focusMcpFormField()
    // shift+tab: m.mcpFormField = (m.mcpFormField + 4) % 5
    case msg.String() == "left" || msg.String() == "h":
        if m.mcpFormField == 1 && m.mcpFormTransport > 0 {
            m.mcpFormTransport--
        }
    case msg.String() == "right" || msg.String() == "l":
        if m.mcpFormField == 1 && m.mcpFormTransport < 2 {
            m.mcpFormTransport++
        }
    case key.Matches(msg, m.keys.Confirm):
        s, err := m.buildMcpServerFromForm()
        if err != nil {
            m.mcpFormErr = err
            return cmds
        }
        m.mcpFormErr = nil
        m.mcpRunning = true
        cmds = append(cmds, m.spinner.Tick, m.doAddMcp(s))
    default:
        var cmd tea.Cmd
        switch m.mcpFormField {
        case 0:
            m.mcpFormName, cmd = m.mcpFormName.Update(msg)
        case 2:
            if m.mcpFormTransport == 0 {
                m.mcpFormCommand, cmd = m.mcpFormCommand.Update(msg)
            } else {
                m.mcpFormURL, cmd = m.mcpFormURL.Update(msg)
```

3. **`EnvLiteral` in codex** — codex uses `--env KEY=VALUE` for all env (both resolved secrets and literals), so both `Env` (resolved) and `EnvLiteral` (inline) become `--env` flags on codex.

4. **`agents picker` for mcp rows** — spec says "reuse the existing per-package picker". 5. **`i` key scope** — `i` adopts the highlighted unmanaged row. The cursor must be in the unmanaged section (below all managed rows). `mcpHighlightedUnmanaged` uses `m.mcpCursor` relative to `len(m.mcpRows)` to determine this.

6. **Schema version** — config currently at `CurrentVersion = 9`. Adding `McpServer` fields is additive (old settings.json missing `mcp_servers` unmarshals fine). Version bumps to 10 on the first write post-upgrade; `make gen-schema` regenerates the schema file.
