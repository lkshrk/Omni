# Omni

Omni describes and reconciles a workstation's desired state across machines.

## Language

**Agent Target**:
An AI coding tool installation that Omni can equip with managed capabilities such as skills, MCP servers, and plugins.
_Avoid_: Agent, client, backend

**Agent Capability**:
A kind of managed content that an Agent Target can consume. Capability support belongs to the target, not to a separate copy of the target's identity.
_Avoid_: Feature, resource type
